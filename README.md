# Telegram-чат на GREEN-API

Текстовый чат на React: вход по данным инстанса GREEN-API, новый диалог по номеру телефона, отправка через `sendMessage` и получение ответов через HTTP API (`receiveNotification` / `deleteNotification`).

Интерфейс рассчитан на Telegram. Если инстанс WhatsApp или MAX, те же методы GREEN-API тоже подойдут: номер уходит как `79001234567@c.us`.

## Локальный запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес из терминала: http://127.0.0.1:5173

Сборка статики:

```bash
npm run build
npm run preview
```

## Подготовка GREEN-API

1. Зарегистрируйтесь в [консоли GREEN-API](https://console.green-api.com/).
2. Создайте инстанс Telegram и авторизуйте его QR-кодом: Telegram → Настройки → Устройства → Подключить устройство.
3. Скопируйте `apiUrl`, `idInstance` и `apiTokenInstance`.
4. Очистите поле webhook URL у инстанса. Иначе `receiveNotification` не отдаёт очередь. После очистки подождите около минуты.
5. В форме входа вставьте эти три значения. Чат пустит дальше только авторизованный инстанс.

Ключ остаётся в `localStorage` этого браузера. В репозиторий и в скриншоты его лучше не класть.

## Как проверить переписку

1. Нажмите «Создать» и введите номер получателя в международном формате: `79001234567`. Номер с `8` и пробелами тоже приводится к `7`.
2. Напишите текст и отправьте. У сообщения появятся состояния: отправлено, доставлено, прочитано.
3. Ответьте на это сообщение из Telegram. Ответ появится в том же чате. Приложение само опрашивает очередь и удаляет обработанные уведомления.

Если у номера нет Telegram, у сообщения будет статус «нет Telegram на этом номере».

## Что делает приложение

- `GET .../getStateInstance/...` — проверка, что инстанс авторизован.
- `POST .../sendMessage/...` — отправка текста, не длиннее 4096 символов.
- `GET .../receiveNotification/...?receiveTimeout=20` — длинный опрос входящих.
- `DELETE .../deleteNotification/.../{receiptId}` — снятие уведомления с очереди.

История чатов хранится локально в браузере и привязана к `idInstance`. Удаление чата стирает его только на этом компьютере.
